# 版本對讀

<https://soaring0616.github.io/version-diff/>

把**聖經恢復本**與**和合本**並排，以「字」為單位比對，標出兩版不一樣的地方；
可以依卷書掃描整卷列出所有差異，每一節都連到原文逐字對照。

起因是和聖徒一起讀詩篇 76:11 時發現兩版對不起來，以弗所書 4:15 也不一樣，
想有個地方可以一卷一卷把差異整理下來。

## 三種用法

| 用法 | 做什麼 |
|------|--------|
| **對讀這一章** | 選一卷一章，兩欄並排。只有和合本有的字標成橘色，只有恢復本有的字標成藍色 |
| **掃描整卷** | 整卷每章都比一遍，依章列出所有有差異的節與差異片語。這是「依卷書列出不一樣的地方」的主力 |
| **我的記錄** | 自己讀到想留下來的觀察，寫在 `data/diffs.js`，會掛在對應的節上 |

兩個選項：**只顯示有差異的節**（預設開）、**忽略標點差異**（預設開）。
兩版的標點習慣本來就不同，不忽略的話整章都會被標成有差異。

網址 hash 可以分享：`#49.4` 開以弗所書第 4 章，`#49.4.15` 直接跳到 4:15
（格式是 `書卷號.章.節`，書卷號見 `js/books.js`）。

## 記錄自己的觀察

頁面上每一節都有「**複製記錄範本**」按鈕，按下去會把那一節的書卷號、章節
和兩邊的差異片語整理成一段，貼進 `data/diffs.js` 的陣列裡，填上 `tag`／`note`／`original` 即可。
存檔重新整理就會出現，沒有建置步驟。

經文本身不要寫進 `data/diffs.js` —— 經文是現場去抓的，這個檔案只放自己的話。

## 資料來源

| 來源 | 用途 | 連結格式 |
|------|------|----------|
| [網上聖經恢復本](https://www.recoveryversion.com.tw/) | 恢復本經文與註解（公開 API，`crossref/` 也是用這組） | 該站為前端渲染，無法直接連到章節，只能連首頁 |
| [信望愛](https://bible.fhl.net/) | 和合本經文（`json/qb.php`） | `new/read.php?chineses=弗&chap=4&sec=15` |
| [biblehub](https://biblehub.com/) | **原文逐字對照**（希伯來文／希臘文 + Strong's）與英文各譯本 | `interlinear/{slug}/{章}-{節}.htm` |
| [bibleread.online](https://bibleread.online/bible/) | 英文恢復本 | `bible/{slug}/{章}/#{節}` |
| [cut.ibibles.net](https://cut.ibibles.net/) | 另一個和合本線上版 | `{NNN}{Book}.htm#{NNN}-{章}`，只到整章 |

兩個版本的經文都在開頁面時即時取得，以 localStorage 快取 30 天，
**repo 裡不存放任何經文資料**，和 `crossref/` 同一套做法。
恢復本經文版權屬台灣福音書房。

## 結構

純靜態、無建置步驟（和 `crossref/` 一樣，CI 不用改）：

| 檔案 | 職責 |
|------|------|
| `js/books.js` | 66 卷書卷表 + 四個外部站各自的書卷代號（fhl／hub／cut／bro） |
| `js/sources.js` | 各來源的逐節網址組法。對方改版只要改這裡 |
| `js/diff.js` | 逐字 LCS 比對，輸出 same／del／ins 段落；可忽略標點 |
| `js/api.js` | 恢復本與和合本的取文與快取 |
| `data/diffs.js` | 自己寫的記錄（手動維護） |
| `js/app.js` | 介面：對讀、掃描整卷、記錄面板、網址 hash |

## 關於標色的脾氣

比對是以「字」為單位做最長共同子序列（LCS）。中文沒有詞界，所以兩版翻法差很多的時候，
共同的字可能散落在句子各處，標色看起來會比較碎。例如弗 4:15 那半句，
兩邊共有的是「惟」「愛」「實」三個字，中間差異的部分各自標色，
讀起來是「惟 ⟨用→在⟩ 愛 ⟨心說誠→裏持守著真⟩ 實」。
骨架還是看得出來，但它不會幫你斷詞。真正要判斷意思，點「原文逐字」回到原文。

演算法本身的不變量有測過：每一欄把 same／標色／自己的標點接回去，
一定等於該版本原本的經文，不會漏字或多字。

## 已知待確認

- `js/books.js` 的 `fhl` 欄位用通行的和合本縮寫，其中**約翰壹／貳／參書**（`約一`／`約二`／`約三`）
  沒有在信望愛站上逐卷確認過。若「信望愛」按鈕開錯頁面，改那三行即可。
- 和合本是透過瀏覽器直接向信望愛的 API 取文，**對方是否開放跨網域（CORS）尚未在瀏覽器實測**。
  若被瀏覽器擋下，頁面會顯示提示並改為只呈現恢復本一欄，每節仍可用「信望愛」按鈕自行開啟對照，
  不會整頁壞掉。
